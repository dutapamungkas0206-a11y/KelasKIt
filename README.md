# KelasKit

Website peminjaman peralatan kelas (HTML, CSS, JavaScript).

## Halaman
- index.html: Beranda
- katalog.html: Katalog dan pencarian barang
- cara-meminjam.html: Tata cara peminjaman
- bantuan.html: Bantuan dan FAQ
- masuk.html / daftar.html: Masuk dan daftar akun
- pengajuan-saya.html: Status pengajuan dan notifikasi
- admin.html: Panel admin (persetujuan peminjaman)

## Foto barang
Letakkan foto di folder `images/` dan samakan nama filenya dengan field `img` di `common.js`.
